\section{Which image-editing tasks help which visual capabilities?}
The controlled experiments above show that image-editing supervision can improve image understanding.
We now ask: \emph{which types of generation data help which visual capabilities?}
Using \methodname, we construct a comprehensive generation-to-understanding transfer map that relates individual I2I supervision tasks to downstream I2T capabilities.
\subsection{Experimental Setup.}
For each I2I supervision task, we initialize from the same BAGEL checkpoint and apply the two-stage training recipe identified in the previous section:
I2I pretraining followed by finetuning on the same 10k LLaVA-Instruct examples~\citep{liu2024llava}. 
We use 50k I2I training samples per task.
We compare every resulting checkpoint against an I2T-only baseline trained on the same LLaVA-Instruct data.
For an I2I task $t$ and an I2T capability $c$, we define the transfer score as:
\[
\Delta(t,c)
=
\operatorname{Acc}(M_t,\mathcal{D}_c)
-
\operatorname{Acc}(M_{\mathrm{I2T}},\mathcal{D}_c),
\]
where $\mathcal{D}_c$ contains all evaluation samples assigned to capability $c$ by \methodname.
Our main analysis considers the 19 capabilities with more than 100 evaluation examples in \methodname. 
The result is shown in \autoref{fig:transfer_matrix}.

\subsection{Transfer patterns}
\paragraph{I2I supervision improves related visual capabilities.}
Several I2I tasks yield gains on understanding capabilities that require closely related visual information.
The clearest example is \textit{Object pointing}: training the model to mark every instance matching a category query produces the largest observed improvement on \textit{Counting} ($+3.57$ pp).
Here, the image-valued supervision explicitly requires identifying individual instances, a visual requirement shared with counting.
Similarly, \textit{Z-depth} produces the largest gain on \textit{Metric 3D relation} ($+2.90$ pp), connecting depth prediction to metric spatial reasoning.
\textit{2.5D segmentation} also substantially improves \textit{2D Ordering} ($+11.58$ pp).
These results show that supervision provided through image targets can improve performance on related visual questions.

\paragraph{Gains also extend across capability families.}
Useful transfer is not limited to these direct correspondences.
\textit{Colorization} yields the largest observed gain on \textit{Visual correspondence} ($+5.71$ pp), while \textit{2D keypoints} performs best on \textit{Multi-view reasoning} ($+7.38$ pp).
These pairs cross the Reconstruction--Reorganization boundary in \methodname, showing that beneficial supervision can also come from tasks outside the target capability's family.
